# Cross-platform dotfiles

This is chezmoi territory. It contains the user-owned configuration intended to
work on macOS and on any Linux distribution

The scope is the home environment: shell configuration, application settings,
themes, templates, and the small integrations needed to apply them. The same
source adapts to each platform without turning into a separate system
configuration layer

System provisioning, package management, operating-system policy, and software
builds live elsewhere in the repository. Keeping those concerns outside this
directory prevents feature creep and keeps the dotfiles portable
